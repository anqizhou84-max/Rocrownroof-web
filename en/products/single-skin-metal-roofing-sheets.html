Frequently asked questions

Can I order the same YX profile in different metals?

Yes. The profiles shown can be roll-formed in prepainted steel, aluminium or stainless steel. Specify the material and profile code when you request a quote.

Is the drawing width the same as effective coverage?

Not necessarily. The table reproduces the width shown on the profile drawing. Ask for the effective installed coverage for your selected profile and joint.

How do I match an existing metal sheet?

Send the profile code if known, plus a cross-section photo or drawing, a measured width and details of the existing joint. Confirm the fit before ordering.

Request a project quote

Include the YX code, material, required thickness or grade, sheet length, surface finish, quantity and destination port.
